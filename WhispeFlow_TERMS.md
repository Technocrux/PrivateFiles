## 4. What WhisperFlow does on your computer

So that there are no surprises, you acknowledge that in normal operation WhisperFlow:

- installs a system-wide keyboard hook in order to detect your dictation key
  while other applications have focus;
- records microphone audio while, and only while, the dictation key is held or
  latched;
- simulates keystrokes and uses the clipboard in order to place the finished
  text into the application you were using;
- reads the title and owning process of the focused window;
- downloads a speech engine and speech model files, at your request, from
  GitHub and Hugging Face; and
- runs, in its signed release form, with the Windows **UI Access** privilege —
  the accessibility mechanism used by screen readers and on-screen keyboards —
  so that it can type into applications running as administrator.

UI Access is not administrator rights. It does not allow WhisperFlow to modify the
system, and WhisperFlow does not request elevation in order to run.

What WhisperFlow does with the information it handles is set out in the Privacy Policy,
